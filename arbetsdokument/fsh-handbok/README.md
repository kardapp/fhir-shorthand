# FSH-handbok: onboarding och presentation

Detta är en samlad struktur för hur vi arbetar med FHIR Shorthand i teamet.

Målgrupper:
- Nya informatiker som ska onboardas till vårt arbetssätt.
- Kollegor och intressenter som behöver förstå vår utvecklingsprocess.
- Presentatörer som ska beskriva vårt upplägg internt eller externt.
